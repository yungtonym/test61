# Калькулятор площадей фигур

Программа позволяет вычислять площади различных геометрических фигур.

## Возможности

- Вычисление площади прямоугольника
- Вычисление площади круга
- Вычисление площади трапеции
- Вычисление площади треугольника

## Используемые формулы

### Круг
$$
S = \pi r^2
$$

где:
- (S) - площадь круга;
- (r) - радиус круга.

### Прямоугольник
$$
S = ab
$$

где:
- (S) - площадь прямоугольника;
- (a) - длина прямоугольника;
- (a) - ширина прямоугольника.

### Треугольник
$$
S = \frac{ah}{2}
$$

где:
- (S) - площадь треугольника;
- (a) - основание треугольника;
- (h) - высота треугольника.

## Запуск программы

Убедитесь, что у вас установлен Python. Введите команду:

```
python main.py
```

## Пример работы

Выберите фигуру:
1 - Круг
2 - Прямоугольник
3 - Треугольник

Ваш выбор: 1
Введите радиус: 5

Площадь круга: 78.54
